# 김지환 — Personal Website

A responsive Korean-language introduction site about financial data science, macroeconomic interests, and research questions. The 탐구 노트 section can be reordered by featured order or title with a stable merge sort implemented in `script.js`.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. The page uses HTML, CSS, and vanilla JavaScript; fonts load from Google Fonts.

## Publish

The `main` branch is connected to the Netlify site `website-q3km`. Pushing a commit to GitHub triggers a new deployment.

## Personalize

Edit the introduction and profile text in `index.html`. Edit the note cards and their descriptions in the `notes` array in `script.js`.
