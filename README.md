# Field Notes — Personal Website

A responsive photo journal built for Lab 7. It includes an interactive before/after comparison slider and two ordering controls, both powered by the stable merge sort in `script.js`.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. The typefaces load from Google Fonts; the artwork is drawn in CSS, so the page itself has no image files to install.

## Publish

1. Create a public GitHub repository named `<your-github-username>.github.io` and push these files.
2. In Netlify, choose **Add new site → Import an existing project** and connect that repository, or use Netlify Drop to upload this folder.
3. Open the deployed URL on desktop and phone and try both sort buttons and the compare slider.

Replace the sample collection in `script.js` with your own photos and captions before submitting if your instructor expects personal images.
